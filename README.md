> AI 코딩 에이전트와 협업하여 만든 아날로그 감성의 다이어리 꾸미기 웹 서비스입니다.

---

## 1. 제품 기획서 (PRD)

### 5W1H 기획
* **Why (목적):** 아날로그 스크랩북의 따뜻한 감성을 디지털 공간에 보존하고 나만의 아지트를 구축하기 위함
* **Who (대상):** Y2K 및 빈티지 문구류(에폭시 스티커, 마스킹 테이프 등)를 좋아하는 대학생 및 직장인
* **What (핵심 기능):** 드래그 앤 드롭을 이용한 스티커 배치, 줄노트 감성의 일기 작성
* **When (시점):** 하루를 마무리하며 소소한 감상을 기록하고 싶을 때
* **Where (환경):** 웹 브라우저 (데스크톱 및 태블릿 화면에 최적화)
* **How (구현):** 코딩 에이전트와 협업하여 HTML, CSS, Vanilla JavaScript로 구현

### 기능의 문제 분해
1. **화면 레이아웃 (뼈대 구축)**
   - 스티커를 고르는 `보관함 영역`과 일기를 쓰는 `캔버스 영역` 분리
2. **디자인 (CSS 스타일링)**
   - 미색 종이 질감의 배경 구현 및 실제 에폭시 스티커 같은 입체적인 그림자(`box-shadow`) 효과 부여
3. **상호작용 (JavaScript 로직)**n   - 보관함 아이템을 드래그하여 캔버스에 복사하는 기능
   - 캔버스 내에 배치된 스티커를 마우스로 잡고 자유롭게 이동시키는 기능
